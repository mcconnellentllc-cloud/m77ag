2. Seed Flow Calibration (gate notch)

The seed gate sets how fast seed moves through the treater. USC does not publish a notch number for each crop. The notch is found with a dry run, and it must be checked again for every new seed type or seed size.

Do not run more than 500 lb per minute (8.3 lb per second). Above that the auger motor can overload (AT500 manual, page 20).

Adjusting the gate

  • Pull back on the spring-loaded coupling and move it to the notch you want on the shaft.
  • Black lever down: gate closed. Black lever up: gate open.

Dry calibration run

  1. Set up so untreated seed can run through and be caught again. Use at least 2,000 lb.
  2. Set the gate to a middle notch to start.
  3. Turn the auger on. Start the stopwatch when the first seed lands in the bottom of the supply hopper. Keep the supply hopper full the whole time, or the reading is not accurate.
  4. Stop the watch when the last seed leaves the supply hopper.
  5. Calculate the rate:

    lb per second = pounds run ÷ seconds
    lb per minute = lb per second × 60
    cwt per minute = lb per minute ÷ 100

  6. Adjust the notch and repeat until the rate is where you want it. Write the notch and rate in the log below.

3. Chemical Pump Calibration

The pump must deliver the label rate in ounces per hundredweight (cwt) at the seed flow set in Section 2.

  1. Premix the slurry in the 35-gallon tank. Mix about 20% extra to fill the lines. Turn on the agitation pump.
  2. Work out ounces needed per minute:

    oz per minute = seed flow (cwt per minute) × slurry rate (oz per cwt)

  3. Pick a nozzle and pressure from the chart below.
  4. Hold the nozzle over a measuring pitcher, put the Chemical Pump switch on Hand, and run until all air is out. Set pressure with the regulator. Pour the liquid back into the tank.
  5. Run exactly one minute into the pitcher. The pitcher should hold the ounces per minute worked out in step 2. Adjust the regulator and repeat until it does.
  6. For treating, set the Chemical Pump switch to Auto. The proximity switch in the supply hopper starts and stops the pump with the seed.

4. Treating Wheat with Pivot Bio

Fall 2026: Certified Byrd CL from Carlson Grain, 502 bu (30,120 lb), already treated with CruiserMaxx Vibrance. The treater applies Pivot Bio only.

Use the rate, water volume and planting window on the Pivot Bio product label for the lot in hand. Pivot Bio's public pages do not list the wheat on-seed rate. Pivot Bio support: 1-877-451-1977, support@pivotbio.com. Pivot Bio is a live microbial product: follow its handling, storage and time-to-plant limits.

Worked example

Seed flow 450 lb per minute = 4.5 cwt per minute. If the label slurry rate were 5 oz per cwt:

4.5 cwt/min × 5 oz/cwt = 22.5 oz per minute → TG-1 at about 40 psi

The 5 oz figure is only for the arithmetic. Replace it with the label rate.

Run time

30,120 lb at 450 lb per minute is about 67 minutes of treating time.
